# SeamlessChain v2

2026-09-22: 顔アンカーと映像の継ぎ目を分離し、通常生成に動きの追加引き継ぎを追加。

- `handoff_NNN.npy`: ReActor 補正済み。次クリップの生成条件。
- `seam_NNN.npy`: 色補正後・ReActor 補正前の末尾。次クリップのフェード開始側。
- State の `continuity_lead_seconds=1`: 同一シーンでは保存済み前クリップの末尾24フレーム（24fps）も生成条件に含める。生成の開始時刻を1秒戻し、生成後に映像と音声の両方から1秒を除く。出力の予定時刻と長さは変えない。
- 初回・シーン変更では追加引き継ぎをしない。redo は既存の `redo_lead_seconds` を使用。
- 整数秒と8フレーム単位を両立する長さだけ追加する。短い前クリップでは切り下げる。24fps以外では設定秒数によって追加が0になる場合がある。
- 古いセッションに seam ファイルがない場合は従来の handoff にフォールバック。過去動画は自動修復されない。
- 次クリップを再生成しない redo では既存の handoff/seam を保持。

## 使用

ComfyUI 再起動後、`LTX-2.5-lip sync-CHAIN+MSR-SCENES-AUTO+ReActor-SeamlessChain-v2-TEST19s.json` を開き実行する。現在の入力画像・音声の先頭から19秒（2クリップ）を新規セッションで生成。旧動画の2:34を再現するテストではない。全編版は末尾 `-v2.json`。

顔補正、MSR、口マスク、フェードの長さは元の設定を維持。追加生成は同一シーンの2クリップ目以降で1秒ずつ。全編の顔固定や二重像の完全除去を保証するものではなく、実映像での比較が必要。
